### Now Start Trading With below Steps

- Click on Start Copy Order ,it will take all today order from master client and copy on all child clients which you manage on ManageClient Screen.

- Manage Client :  Click on Manage Client Menu , it will open below screen

![Product reference image](https://bhansalisoft.com/evantosnap/binance/03.png)

 Fill below Details

- Client Unique Name :  Enter Unique name

- Exchange Api Key :  Enter Your  Binance Account API Key

- Exchange Secret Key :  Enter Your Binance Account Secret Key

 Help :[How to get Binance Account API Key and Secret Key]( https://www.binance.com/en/support/faq/360002502072)

- Active : You can active and Deactive client anytime

- Exchange : Select Binance/Bybit Exchange from DropDown.

 Note :We are not store any data so not responsibe for any financial loss/profit . all this data save in local xml file :ClientData.xml

- order value(%):  default value is : 100%, order will be percentage of Child account wallet balance. if you add 10% and child account wallet balance is 100$ then trade will be 10$ on child account.

- Click on Check Balance button for check All coin balance available in your account.

![Product reference image](https://bhansalisoft.com/evantosnap/binance/04.png)

- Manage Trading Symbol : You can manage all trading symbol for Spot and FutureUSDT, FutureCoin.

![Product reference image](https://bhansalisoft.com/evantosnap/binance/05.png)

- Enter Below detail

- Binance Symbol : Enter Binance Symbol  like ETHUSDT

- Exchange : select option from dropdown , BinanceSpot, BinanceFutureUSDT,BinanceFutureCoin.

![Product reference image](https://bhansalisoft.com/evantosnap/binance/02.png)
